<h2><a href="https://www.geeksforgeeks.org/problems/form-a-number-divisible-by-3-using-array-digits0717/1">Form Divisible by 3 from Array</a></h2><h3>Difficulty Level : Difficulty: Easy</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p><span style="font-size: 18px;">You are given an array&nbsp;<strong>arr[]</strong>&nbsp;of integers. You can form new integers by concatenating any two integers from the array (treating them as strings). For example, given&nbsp;<strong>19</strong>&nbsp;and&nbsp;<strong>4</strong>, you can form&nbsp;<strong>194</strong>&nbsp;and&nbsp;<strong>419</strong>.</span></p>
<p><span style="font-size: 18px;">Determine whether it is possible to construct a single integer using all the digits of the given numbers (in any order) such that the resulting number is <strong>divisible </strong>by <strong>3</strong>.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input:</strong> arr[] = [40, 50, 90]
<strong>Output:</strong> true
<strong>Explanation:</strong> One such number is 405090.</span></pre>
<pre><span style="font-size: 18px;"><strong>Input:</strong> arr[] = [1, 4]
<strong>Output:</strong> false
<strong>Explanation:</strong> The numbers we can form are 14 and 41. But neither of them are divisible by 3.</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>1 ≤ arr.size(), arr[i] ≤ 10<sup>5</sup></span></p></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Arrays</code>&nbsp;<code>Mathematics</code>&nbsp;
