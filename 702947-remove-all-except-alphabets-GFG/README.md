# [Remove All Except Alphabets](https://www.geeksforgeeks.org/problems/remove-all-characters-other-than-alphabets4923/1)
## Easy
Given a string s, remove all characters except lowercase and uppercase alphabets (a-z and A-Z) and return the resulting string.If no alphabetic characters remain after removal, return an empty string.Examples:Input: s = "$Gee*k;s..fo, r'Ge^eks?"
Output: "GeeksforGeeks"
Explanation: All characters other than alphabets are removed from the string "$Gee*k;s..fo, r'Ge^eks?", resulting in "GeeksforGeeks". 
Input:  s = "{{{}}&gt; *&amp; ^%*)"
Output: ""
Explanation: The string "{{{}}&gt; *&amp; ^%*)" does not contain any alphabetic characters, so after removing all non-alphabet characters, the resulting string is empty.
