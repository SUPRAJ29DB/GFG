# [String with Number at End](https://www.geeksforgeeks.org/problems/string-with-numbers-at-its-end5749/1)
## Easy
Given string s that is&nbsp;appended with a number at last. The task is to check whether the length of string excluding that number is equal to that number. Examples:Input:  s = "geeks5"
Output: 1
Explanation: Length of geeks is 5 and the last number is also 5.Input:  s = "geek5"
Output: 0
Explanation: Length of geek is 4 and the last number is 5.
