# [Divisibility by 4 Check](https://www.geeksforgeeks.org/problems/check-if-divisible-by-43813/1)
## Easy
Given a number in form of a string s. Check whether it is divisible by 4 or not.Examples :Input: s = "1124"
Output: true
Explanation: The last two digits of "1124" are 24. Since 24 is divisible by 4, the given number is also divisible by 4. Hence, the output is true.
Input: s = "7"
Output: false
Explanation: As 7 % 4 = 3, the number is not divisible by 4. Hence, the output is false.
